# Triage labels

Use these five labels exactly:

- `needs-triage`: the request has not been classified.
- `needs-info`: a decision or information is missing.
- `ready-for-agent`: the issue is fully specified and safe for an implementation agent.
- `ready-for-human`: implementation and automated review are complete; human review is required.
- `wontfix`: the request is rejected or outside the agreed scope.

Additional labels may describe areas, but they must not replace the five canonical workflow labels.
